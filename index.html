PROJECT 02

Linux Server Health Monitoring and Automation

Developed a Bash-based Linux server monitoring solution to automate system resource monitoring, service availability checks, and health report generation. Implemented CPU, RAM, and disk utilization monitoring with threshold-based health detection. Integrated SSH and Apache service monitoring, system log collection using journalctl, and Cron scheduling to execute automated health checks every five minutes. Generated consolidated server health reports to help administrators identify potential resource and service issues.

Linux Ubuntu Bash Scripting Shell Commands Cron systemctl, journalctl Git GitHub
